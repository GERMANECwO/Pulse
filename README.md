# Pulse

Аудиовизуализатор и ритм-игра в одном файле. Открой в браузере — и звук превращается в свет.

## Возможности
- Визуализация под свою музыку: локальные файлы, звук программ (Windows) или встроенный демо-трек.
- Ритм-механика: попадания в такт, комбо, точность, калибровка задержки, «право на ошибку».
- 15 палитр + авто-смена, ночной режим, 4 режима сцены (клип / кольцо / волна / лучи).
- Синхронный текст песни (LRCLIB) и распознавание трека. (в разработке)
- Плейлист с перетаскиванием и перемешиванием.
- RU/EN — язык определяется по браузеру автоматически.

## Запуск
1. Сохрани файл как `index.html`.
2. Открой в браузере. Для захвата системного звука используй Chrome/Edge (пункт «Звук программ»).
3. Либо задеплой на GitHub Pages / Netlify — работает как обычный сайт.

## Управление
Клик / пробел — попасть в такт · M — режим · C — палитра · N — ночь · P — пауза · Esc — меню.

# PULSE (English)

An audio visualizer and rhythm game in a single HTML file. Open it in a browser and watch sound turn into light.

## Features
- Visualizes your music: local files, system sound (Windows) or a built-in demo track.
- Rhythm gameplay: beat hits, combo, accuracy, latency calibration, grace miss.
- 15 palettes + auto-switch, night mode, 4 scene modes.
- Synced lyrics (LRCLIB) and track recognition. (in progress)
- Playlist with drag & drop and shuffle.
- RU/EN, auto-detected from browser language.

## Run
1. Save the file as `index.html`.
2. Open in a browser (Chrome/Edge for system-audio capture), or deploy to GitHub Pages / Netlify.

## Controls
Click / Space — tap to the beat · M — mode · C — palette · N — night · P — pause · Esc — menu.
